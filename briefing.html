What it appears to do

Warehouse safety agent: detect worker–equipment proximity risk, search history, reason, alert.

  1. Status bar — VSS connected?, archive clip counts, W&B inference ready (GET /api/status).
  2. Primary clip — Curated warehouse aisle segment with optional YOLO person bbox overlay on the video.
  3. Run agent investigation
    • Refresh Cosmos captions + YOLO evidence for the event
    • Hybrid search the VAST archive for similar proximity moments
    • Show three curated historical incidents with live similarity when available
    • W&B (or fallback) → severity, recurring pattern, recommendation
    • Create a safety alert (kept in an in-memory log, GET /api/alerts)
  4. Optional — Ask the archive (VAST agent Q&A) or Search VAST for free-form hybrid retrieval.

Demo story for judges: search → reason → act, with each partner visible on screen.
